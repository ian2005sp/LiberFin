# LiberFin 💰

## Gestor inteligente de gastos personales

LiberFin es una aplicación web diseñada para ayudar a los usuarios a organizar sus finanzas personales, analizar sus hábitos de consumo y tomar mejores decisiones financieras mediante el uso de herramientas computacionales.

## Problema que resuelve

Muchas personas tienen dificultades para controlar sus gastos, identificar patrones de consumo y planear objetivos financieros futuros. LiberFin busca solucionar este problema mediante un sistema que registra movimientos, analiza información y genera recomendaciones personalizadas.

## Funcionalidades principales

- Registro de ingresos y gastos.
- Historial financiero.
- Dashboard con balance general.
- Análisis de gastos por categoría mediante gráficas interactivas.
- Recomendaciones financieras automáticas.
- Detección de gastos inusuales.
- Proyecciones de ahorro.
- Simulador de compra inteligente.
- Resumen mensual automático.

## Herramientas utilizadas

- Python: lenguaje principal para desarrollar la lógica de la aplicación.
- Streamlit: creación de la interfaz web.
- Pandas: análisis y procesamiento de datos.
- Plotly: generación de gráficas interactivas.
- GitHub: almacenamiento y control del proyecto.
